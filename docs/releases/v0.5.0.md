This release adds a single-file Windows setup experience while preserving the project's explicit authorization boundaries.

## Highlights

- Download one `codex-feishu-notify-windows-v0.5.0-setup.exe`, double-click it, and continue in the existing graphical settings tool.
- Installs the management files per-user under `%LOCALAPPDATA%\Programs\CodexFeishuNotify\v0.5.0` and creates a Start menu shortcut.
- Does not require administrator rights and carries an `asInvoker` Windows manifest.
- Embeds the same reviewable source ZIP shipped beside it in this Release.
- Rejects ZIP traversal and alternate-data-stream paths, checks required payload files, and restores the prior same-version directory if replacement fails.
- Includes automated build, extraction, clean-reinstall, PowerShell 7, and Windows PowerShell 5.1 checks.

## Install

1. Install and authenticate `lark-cli` first, or follow the linked `lark-coding-agent-bridge` prerequisite guide in the README.
2. Download the setup EXE and its `.sha256` file.
3. Verify the SHA-256 value, then double-click the EXE.
4. In the graphical settings tool, enter the target Feishu chat ID, verify the Lark profile and schedule, and click `安装通知`.
5. Restart Codex, then review, trust, and enable the installed lifecycle hooks in Codex.

The setup EXE opens the installation wizard; it does not silently create a Feishu application, approve QR authorization, broaden access to coworkers, or bypass Codex hook trust.

## Downloads

- `codex-feishu-notify-windows-v0.5.0-setup.exe`: recommended one-click Windows setup launcher.
- `codex-feishu-notify-windows-v0.5.0-setup.exe.sha256`: setup executable checksum.
- `codex-feishu-notify-windows-v0.5.0.zip`: portable source and script package.
- `codex-feishu-notify-windows-v0.5.0.zip.sha256`: ZIP checksum.

## Signing and privacy

The setup executable is not currently Authenticode-signed and may show an unknown-publisher SmartScreen warning. Verify the attached SHA-256 value and repository URL before running it. The executable and ZIP contain no local chat ID, Lark credentials, queue data, logs, backups, or machine-specific settings.
