This is the first packaged GitHub release of the Windows Codex-to-Feishu notifier.

## Highlights

- Sends real Codex completion and permission-wait events to Feishu through `lark-cli`.
- Uses lifecycle readiness and a strict Stop/completion gate to reduce unrelated or duplicate notifications.
- Provides an adaptive PowerShell graphical settings tool for connection, notification, schedule, installation, repair, and uninstall.
- Supports daily cross-midnight windows, Singapore/China/custom holiday calendars, and selected all-day weekdays.
- Adds one dynamic `马上开始 / 立刻停止` control that temporarily overrides the current delivery period without changing the saved schedule.
- Keeps Feishu delivery, Windows PowerShell Toast notifications, and the scheduled-task master switch independent.
- Uses an atomic local queue, expiry, idempotency markers, bounded retries, redacted logs, and safe Hook coexistence.

## Installation

1. Download and extract `codex-feishu-notify-windows-v0.4.0.zip`.
2. Install and sign in to `lark-cli` first.
3. Double-click `Open-Settings.cmd`.
4. Fill in the Feishu chat ID, review the schedule, and click `安装通知`.
5. Restart Codex, then review, trust, and enable the newly installed or changed Hooks in Codex.

The release archive contains no local chat ID, Lark credentials, queue data, logs, or machine-specific configuration. Verify the download with the accompanying `.sha256` file.

## Platform and boundaries

- Windows Task Scheduler and PowerShell only.
- Notification-only: it does not remotely approve requests, inject terminal input, or continue Codex tasks.
- Built-in holiday calendars currently cover Singapore 2026–2027 and China 2026.

See `README.md`, `CHANGELOG.md`, and `docs/migration-from-local.md` for configuration, upgrade, and migration details.
