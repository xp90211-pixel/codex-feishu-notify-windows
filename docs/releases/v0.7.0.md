# v0.7.0：新状态通知与全部任务停止提醒

发布日期：2026-09-21。

- 新安装默认只发送当前运行时段内的新事件；历史及被新活动取代的未发完成项转入可恢复隔离区。
- 新增可选的“全部本机 Codex 任务已停止或等待介入”飞书汇总，每个符合条件的计划时段一次。
- 单项完成文案改为“本轮回复完成”，明确显示事件时间。
- 保留既有无闪窗宿主、定时任务、独立 PC 通知、收件人和隐私选项。
- 安装事务管理新模块及汇总设置，升级保留旧选择；PowerShell 7 / 5.1 与发布包校验均增加离线测试。

## 安装与升级

本 Release 提供 setup EXE、便携 ZIP 及各自的 SHA-256 校验文件。下载后先核对对应校验值，再运行安装器。安装器先部署管理程序；点击设置器中的“安装通知”才会升级通知运行时。

旧安装会保留既有选择；没有新字段的旧配置需显式开启“只提醒新状态”，全部任务停止汇总仍为可选功能。启用方式、内部状态接口边界与测试范围见 [通知新鲜度说明](https://github.com/xp90211-pixel/codex-feishu-notify-windows/blob/v0.7.0/docs/notification-freshness.md)。

## 验证与限制

- 发布流水线执行 PowerShell 7 / Windows PowerShell 5.1 回归、安装事务回滚、无控制台启动、手动计划控制、离线新通知测试和安装器构建/解包/覆盖安装检查。
- 新通知测试共 70 项断言，不向真实飞书发送测试消息；离线通过不等于真实定时边界和收件人的现场验收。
- 汇总提醒依赖 Codex 桌面应用的内部只读本机状态接口；未知或不完整状态时不提醒，未来客户端变动可能需要适配。
- 安装器尚未使用 Authenticode 代码签名，Windows SmartScreen 可能显示“未知发布者”。请确认来源为本仓库并核对 SHA-256；不愿运行未签名 EXE 时可使用 ZIP。
