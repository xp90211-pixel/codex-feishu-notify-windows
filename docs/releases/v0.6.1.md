# v0.6.1 - Console-free notification launchers

本版把此前本机的“防命令行闪窗”修补纳入公开源码、新安装、原地升级和图形设置器。

- 安装时使用 Windows 自带 .NET Framework 编译器，离线构建 GUI 子系统 `notification-host.exe`；源代码随 setup EXE 和 ZIP 提供。
- 计划投递、完成通知和通知链转发使用无控制台子进程，正确保留中文、JSON 引号、空格和尾部反斜杠；不是只设置 `WindowStyle Hidden`。
- 五个生命周期 Hook 复用已有 shell，不嵌套启动 PowerShell；保持同步状态处理。
- 识别旧 PowerShell 动作与早期本机 host 动作，保留第三方 notify 包装器、飞书配置、时间计划和开关；后续修改计划不会回退启动方式。
- 安装事务同时备份和恢复 host 源码与 EXE；诊断和卸载能够识别新的任务动作。
- 新增 PowerShell 7 / Windows PowerShell 5.1 的无控制台、参数边界、输出管道及升级回归测试。

## 升级

1. 下载 setup EXE 及同名 `.sha256` 并核对 SHA-256，或解压 ZIP。
2. 打开新版设置器，核对原安装目录与任务名，点击“安装通知”。只运行 setup 不会替换正在生效的运行脚本。
3. 重新打开 Codex，审查并信任发生变化的 Hook；本项目不会修改 Hook 信任记录或其他飞书桥接器。
4. 点击“检查配置”。需要发送真实测试通知时由你另行确认。

setup EXE 与生成的启动器均未代码签名。第三方包装器自身的窗口行为不在本项目控制范围内；额外 Windows Toast 与 Codex 自带通知的开关仍互相独立。
