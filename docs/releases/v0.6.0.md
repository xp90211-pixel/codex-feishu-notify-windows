# v0.6.0 — 可靠投递、安全升级与独立保存

本次根据审阅结果修复配置、发送确认、授权事件、启停竞态和打包边界。

## 主要改进

- 使用离线 TOML 解析器，正确处理根级 notify、多行数组、注释和 UTF-8；安装失败恢复原文件、Hook 和计划任务。
- 发送必须同时取得退出码 0、JSON code 0 与飞书 message ID。空白、非 JSON、未知回包、失败或超时均保留待发项；回执先落盘再移除队列。
- 采用跨进程排空锁和提交前状态锁；独立运行 drain 也受持久总开关约束。“马上开始”改为临时计划触发器，不再另开非托管排空进程。
- 授权等待按请求分别记录；无 ID 时使用本地代数和输入哈希；无关工具事件不再清除等待状态。
- 新安装默认关闭任务/结果摘要，升级保留已有配置与未指定字段；增加 JSON 敏感字段脱敏。
- “保存设置”与安装/升级分开；新增状态原因、下一次允许发送、实际回执和需确认的“发送测试通知”。PC-only 配置无需飞书连接信息。
- DryRun 完全只读；日志轮转与过期状态/suppressed 清理；支持 CODEX_HOME，诊断使用相同的运行计划生成器。
- 逐文件发布白名单与成品 ZIP 扫描，拒绝额外文件、路径穿越及未批准的二进制内容。

## 下载与升级

提供 setup.exe、便携 ZIP 及两者的 SHA-256。安装器未商业签名，请核对来源和哈希。

运行新版 setup.exe 后，在设置器里点击“安装通知”才会更新实际运行脚本。已有 v0.5 配置会保留；安装后重新打开 Codex 并审查/信任变化的 Hook。日常修改用“保存设置”，不必重新安装。

旧配置若已开启摘要，升级不会擅自关闭；敏感场景请自行取消任务/结果摘要。

## 验证与边界

增加离线原生 CLI 故障模拟、Unicode 参数、超时、并发、防重、DryRun 不变性与 Windows 计划任务事务测试，并同时覆盖 PowerShell 7 / 5.1。成品安装器包含解包、重复安装、GUI 冒烟和不安全载荷拒绝测试。

没有自动进行真实飞书消息发送、扫码或授权；真实连接请由你点击“发送测试通知”。关闭不能撤回已经提交的在途请求。缺少稳定请求 ID 时，任意外部乱序的完全因果关联仍不可保证；多义匹配保留到会话/回合结束或过期。

完整对应关系与测试命令见 [审阅整改记录](../review-remediation.md)。
